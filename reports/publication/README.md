# Published reports

This folder contains the completed Phase 1 and Phase 2 publications. For the clearest overview,
start with the combined report, which includes the latest model-optimization and sealed-test evidence.

## Recommended reading order

1. **[Combined Phase 1 + Phase 2 research report (PDF)](Corporate_Financial_Deterioration_Combined_Phase1_Phase2_Research_Report.pdf)**

   The primary, integrated account of the business question, data, methodology, results,
   limitations, and conclusions.
2. **[Phase 2 model optimization and out-of-time results](Phase2_Model_Optimization_and_Out_of_Time_Results.md)**

   A concise technical supplement covering model comparison, workload, and sealed-test evidence.
3. **[Phase 2 development case study (PDF)](Corporate_Financial_Deterioration_Phase2_Portfolio_Case_Study.pdf)**

   A pre-optimization snapshot of the expanded-sample methodology, horizon comparison, and
   development evidence. Use the combined report for the final sealed-test result.
4. Phase-specific research reports

   Detailed records of the benchmark and expanded development study.
